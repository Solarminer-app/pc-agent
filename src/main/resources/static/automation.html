GLOBALE FREIGABE

Remote-Steuerung

Wenn du die Remote-Steuerung ausschaltest, kann kein SolarMiner Node diesen Agenten kontrollieren. Die Dev-Fee wechselt sofort zurück auf den Proxy-Tarif von 1 %.

SICHTBARKEIT IM NETZWERK

LAN-Sichtbarkeit

Ein anderer PC-Agent teilt hier nur Worker und Ertrag (schreibgeschützt). Steuerbar bleibt jeder Agent nur auf seinem eigenen PC.

Wallet-Ziele sind standardmäßig privat. Bei Freigabe können andere gefundene PC-Agents die Ziele laden, aber nicht speichern oder ändern.

WORKER-FREIGABEN

Für die Node verfügbare Worker

Die Freigaben gelten nur, wenn die globale Remote-Steuerung aktiviert ist. Lokale Start- und Pause-Aktionen bleiben davon unabhängig.
