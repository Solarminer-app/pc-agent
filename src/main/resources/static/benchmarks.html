Deine GPUs. Ihr nächstes Level.

Ein geführtes Setup. Ein eigener Live-Arbeitsplatz pro GPU.

    GPUs auswählen

    Wähle die GPUs für diesen Lauf. Jede bekommt eine eigene Seite in einem neuen Tab.

    Tempo bestimmen

    Zeitangaben gelten pro GPU ab ihrem ersten Test, für alle gewählten Kombinationen zusammen. Schnell begrenzt die Messarbeit auf 18 Minuten, Mittel auf 55 Minuten. Warteschlange, Treiberbefehle und sichere Wiederherstellung kommen hinzu. Weniger Umfang bedeutet weniger Abdeckung, keine gelockerten Sicherheitsgrenzen.

    Tests & Grenzen

    Wähle pro GPU die installierten Coin-/Miner-Tests und die maximale Temperatur. Deine automatischen Wechselrechte bleiben erhalten.

    Das Zeitbudget wird auf alle ausgewählten Tests verteilt. Schnell wählt zunächst einen verfügbaren Coin-/Miner-Test pro GPU; weitere Tests sind optional und erhalten weniger Zeit.

    Startet nach erfolgreichen Messungen die gespeicherte Coin-, Miner- und Betriebsmodus-Konfiguration. Ein neuer manueller Stopp oder ein Sicherheitsfehler verhindert den Start. Sonst wird der vorherige Zustand wiederhergestellt.

    Prüfen & starten

    Die ausgewählten GPUs werden vorübergehend angehalten. Jede wird nach ihrem letzten Test unabhängig wieder freigegeben.
